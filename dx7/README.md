# sloopDX factory voices as DX7 SysEx

Source: [zvenson/dxsloop](https://github.com/zvenson/dxsloop) at commit
[`8c1035b`](https://github.com/zvenson/dxsloop/tree/8c1035b79d860edcb6f23556910206332669dac8),
file [`firmware/src/dx7_bank.h`](https://github.com/zvenson/dxsloop/blob/8c1035b79d860edcb6f23556910206332669dac8/firmware/src/dx7_bank.h)
(generated by [`tools/gen_dx7_bank.py`](https://github.com/zvenson/dxsloop/blob/8c1035b79d860edcb6f23556910206332669dac8/tools/gen_dx7_bank.py)).
The voices are original to sloopDX and licensed GPL-3.0-only by Sven Trogus
([LICENSING.md](https://github.com/zvenson/dxsloop/blob/8c1035b79d860edcb6f23556910206332669dac8/LICENSING.md)).

| File | Content |
|---|---|
| `sloopdx-factory.syx` | DX7 32-voice bulk dump: the 20 synth voices, slots 21-32 INIT VOICE |
| `sloopdx-dxkit-drums.syx` | The 17 "DX KIT" drum voices, slots 18-32 INIT VOICE - approximations only, see below |
| `extract_sloopdx.py` | Regenerates both from `dx7_bank.h` |

Both files are standard 4104-byte VMEM dumps (`F0 43 00 09 20 00 ... checksum F7`). The packing
mirrors the firmware's `dx_pack()`; a round trip through a Python mirror of its `dx_unpack()`
reproduces every one of the 155 voice parameters of every voice.

## Why a bare .syx does not sound like sloopDX

The DX7 engine of sloopDX is a port of Dexed's msfa and, by its own header comment, renders a plain
note "99 % of samples identical" to Dexed
([dx7_core.c](https://github.com/zvenson/dxsloop/blob/8c1035b79d860edcb6f23556910206332669dac8/firmware/src/dx7_core.c)).
The voice data is therefore not the problem. What a DX7 bulk dump cannot carry is the *preset*
around the voice ([`DX7_PRESETS` in eng_dx7.c](https://github.com/zvenson/dxsloop/blob/8c1035b79d860edcb6f23556910206332669dac8/firmware/src/eng_dx7.c)):
effect sends, mono/poly and a loudness trim. Reproduce these on the receiving side.

Level trims come from
[`preset_trim.h`](https://github.com/zvenson/dxsloop/blob/8c1035b79d860edcb6f23556910206332669dac8/firmware/src/preset_trim.h)
(stored in 1/2 dB steps, measured to -23 LUFS by `tools/level_presets.py`). Without them, CLAV,
SLAP BASS or MARIMBA come out more than 10 dB quieter than ORGAN or EPIANO 2: easily mistaken for
"weak" voices. Mono matters for 808 SUB (pitch-envelope drop) and the basses/leads; on a DX7 it is a
function parameter, not voice data, so a bulk dump cannot hold it.

### Shared effect buses (sloopDX defaults, [params.c](https://github.com/zvenson/dxsloop/blob/8c1035b79d860edcb6f23556910206332669dac8/firmware/src/params.c), [fx.c](https://github.com/zvenson/dxsloop/blob/8c1035b79d860edcb6f23556910206332669dac8/firmware/src/fx.c))

- **Chorus**: stereo, two modulated delays of roughly 9-17 ms, LFOs in antiphase; rate 40/127, depth 60/127, return 100 %.
- **Delay**: tempo-synced 1/8 note (90 BPM default, i.e. 333 ms), feedback 60/120 (loop gain about 0.42), low-passed feedback (colour 70/127), mono return 90/127.
- **Reverb**: 4-line FDN with two diffusers, size 90/127, damping 60/127, no pre-delay. By my estimate from the loop gain (0.80) and line lengths (35-63 ms), RT60 is about 1.5 s: a medium room/hall rather than a large hall.
- Master: brick-wall limiter; an optional 110 Hz low-cut exists for the built-in speaker (off for line out).

On Dexed or a DX7, use one shared chorus/delay/reverb on aux sends and set each part's sends from the
table, scaled to 0-100 %.

## Drum kit: approximations

The drum voices rely on features outside DX7 voice data, applied by
[`drums.c`](https://github.com/zvenson/dxsloop/blob/8c1035b79d860edcb6f23556910206332669dac8/firmware/src/drums.c):

- **noise operators**: SNARE (OP6), CLAP (OP4, OP6), the hats, CRASH, SHAKER replace a sine with
  sample-and-hold noise; a DX7 plays a sine there, so these sound tonal and metallic;
- **pitch sweep** at the hit (e.g. KICK 808: 20 semitones over 28 ms) and **multi-hit bursts**
  (CLAP: 4 hits, 11 ms apart);
- fixed **trigger notes** (KICK 808 on MIDI 31, KICK PUNCH 33, SNARE 54, TOM LOW 43, TOM HIGH 50, CONGA 62, most others 60) and hat choke groups.

The kicks, toms, conga, cowbell and clave are usable; anything with noise is not faithful.

## Regenerating

```bash
git clone --depth 1 https://github.com/zvenson/dxsloop.git
```

```bash
python3 extract_sloopdx.py dxsloop/firmware/src/dx7_bank.h .
```
